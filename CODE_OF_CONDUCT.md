# Code of conduct

We want this project to be a welcoming place for instructional designers, developers, and anyone learning either craft.

## Our standards

- Be kind and assume good intent.
- Give feedback on the work, not the person.
- Welcome newcomers and questions at every level of experience.
- Respect other people's time, pronouns, and boundaries.

Harassment, personal attacks, and discriminatory language aren't welcome here.

## Enforcement

Maintainers may edit or remove comments, issues, and contributions that break these standards, and may block repeat offenders. To report a concern, use the private "Report a vulnerability" button on the Security tab, or contact a maintainer through their GitHub profile.

This code of conduct is adapted from the Contributor Covenant, version 2.1.
