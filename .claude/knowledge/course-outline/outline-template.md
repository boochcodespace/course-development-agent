# Course Outline Template Reference

This is the canonical template for course outlines. Follow this structure unless the user explicitly requests a different format.

## Template

```markdown

## Course Overview
- **Target Audience:** [Role, experience level, and assumed prior knowledge]
- **Delivery Format:** [ILT / VILT / Self-Paced / Blended]
- **Estimated Duration:** [Total hours, days, or weeks]
- **Prerequisites:** [Required prior courses, knowledge, or system access]
- **Course Version:** [Version number if applicable]

## Course Description
[2-3 sentences describing what the course covers, who it's for, and what learners will walk away with. Write this in plain language, not marketing copy.]

## Course-Level Learning Objectives
By the end of this course, learners will be able to:
1. [Bloom's verb] + [observable, measurable outcome] + [context]
```

## Notes on Using This Template

**Duration estimates by format:**
- ILT: Include time for discussion, demos, Q&A. A "30-minute module" in self-paced might need 45-60 minutes in ILT.
- VILT: Add 10-15% buffer for tech issues, chat engagement, and breakout logistics.
- Self-paced: Estimate based on content consumption only. Keep lessons to 15-25 minute chunks.

**Module count guidance:**
- Half-day workshop: 2-4 modules
- Full-day training: 4-7 modules
- Multi-day bootcamp: 5-10+ modules across days
- Self-paced course: 4-8 modules, each with 2-5 lessons

**Assessment variety:**
Avoid using only one assessment type across the whole course. Mix it up:
- Knowledge checks (quick recall, multiple choice)
- Hands-on labs (apply in a system or sandbox)
- Scenario-based exercises (analyze a situation, make a recommendation)
- Role-play or discussion (VILT/ILT only)
- Capstone or portfolio project (advanced courses)
